## Context

`app/web/index.html` 是单文件（内联 CSS+JS）。当前用大量 emoji 表达状态/分区/操作，并有多处 linear-gradient，整体偏"AI 生成 SaaS 看板"味。行为逻辑（fetch/render/post）保持不动，只改视觉层与文案。

## Goals / Non-Goals

**Goals:**
- 去掉全部装饰性 emoji，改文字标签 + 语义色。
- 克制的"操作台"视觉：单强调色、等宽字体用于编号/ID/时间、去渐变。
- 门禁区是唯一视觉重点。

**Non-Goals:**
- 不改任何后端/API/交互行为。
- 不引入前端框架或构建步骤（仍是单文件内联）。
- 不改布局信息架构（仍是三 tab：全盘/门禁/需求池）。

## Decisions

- **配色**：`--bg` 近白灰、`--surface` 白、`--line` 细灰、`--ink` 近黑、`--dim` 中灰、强调 `--accent` 靛蓝(#3b5bdb 一档)。语义色：主攻红、运营/进行蓝绿、维护/收租绿、雪藏/归档灰——**仅用于小色点和左竖线，不铺大面积、不用渐变**。
- **字体**：正文系统无衬线；`--mono`(ui-monospace) 用于项目ID、提议 #编号、时间、args。
- **状态**：STAGES 文案去 emoji（"火花/验证/主攻/运营/维护/雪藏/归档"）；卡片左竖线按状态取语义色；主攻卡片字号略大、竖线最重。
- **tab**：去 emoji，纯文字"全盘/门禁/需求池"；门禁未处理数用等宽小徽标。
- **门禁提议卡**：去 💡，理由直接排版呈现；action 用等宽 tag；按钮"批准/驳回"纯文字，批准填强调色、驳回描边。
- **kind 角标**：纯文字"商业/工具"（去 💰🔧），弱灰底小标签。
- **保留符号**：✓（勾选完成）、×（删除/驳回），通用无歧义。
- **去掉**：header 的脉冲圆点保留（是"运行中"的功能指示，非装饰）但改素一点；焦点/需求池/空态里的 emoji 全清。

## Risks / Trade-offs

- 纯 CSS/文案改动，风险低。注意 CSS 选择器特异性不要互相覆盖（padding/margin）。
- 去 emoji 后需确保状态仍一眼可辨——靠左竖线颜色 + 文字标签双重编码，不依赖颜色单一通道（照顾色觉障碍）。
