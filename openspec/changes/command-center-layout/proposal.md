## Why

去 emoji 后界面干净了，但仍是"通用管理后台"——项目平铺成流水账，没体现用户的操作系统（四桶法 + 主攻唯一 + 此刻聚焦）。界面应该替用户思考，把"按桶管理、主攻最重、焦点优先"变成结构本身。

## What Changes

- **全盘 tab 重构为"指挥室"布局**：
  - 顶部**桶位概览条**：主攻/运营/维护/雪藏 各几个，一眼看全盘分布。
  - **此刻聚焦做成报头**：页面最醒目的区块，是每天第一眼看的"当前指令"。
  - **项目按桶分组**呈现，不再单一平铺：主攻组最重（整行、大字、显眼左�edge），运营/收租居中，雪藏/归档收窄变灰。
  - 卡片显示**项目 ID**（等宽字体，signature 落地）。
- 状态语义色加深、加宽左竖线，让桶位一眼可辨（含色觉友好：色 + 文字双编码）。
- 仍是纯前端（`app/web/index.html`），数据结构、API、行为零改动。

## Capabilities

### Modified Capabilities
- `project-management`: 已有"看板展示"要求（文字化、无 emoji）保持；本 change 增加"按桶分组 + 桶位概览 + 焦点报头"的布局要求。

## Impact

- 代码：仅 `app/web/index.html`（renderBoard 布局重构 + 样式）。
- 无 API/store/MCP/schema 改动；沿用现有 /api/state 返回字段。
- 验证：node --check + headless 截图确认桶分组、概览条、焦点报头、项目ID 呈现，且无残留装饰 emoji。
